# Quickstart: Improving goal-kit effectiveness

## What This Goal Addresses

Make goal-kit smarter by improving:
1. **Insights** - Deeper, actionable project analysis
2. **Experience** - Friction-free CLI interactions  
3. **Assistance** - Proactive contextual help

## Quick Start

```bash
# View project status (now with enhanced insights)
goalkeeper status

# Check goal progress (now with recommendations)
goalkeeper goals

# Get milestone updates (now with context)
goalkeeper milestones
```

- Analysis detects patterns and provides recommendations
- Commands have smarter defaults (fewer flags needed)
- Contextual suggestions appear based on project state
